# Smart shelf picker

The manual shelf-check screen keeps action-level checking unchanged but makes large shelf lists faster to navigate.

- Default filter is **Cần kiểm**, hiding completed shelves.
- Search matches shelf label/key plus contained POG, location, ITEMID and product name.
- Priority order is: shelves with Sai/Review, in-progress shelves, untouched shelves, completed shelves.
- Only the first 12 shelves are shown while browsing; **Xem thêm** reveals another 12. Search results are not artificially limited.
- **Tiếp tục nhanh** opens the highest-priority unfinished shelf.
- Shelf cards use a compact two-column layout on larger screens and one column on phones.
- Completing a shelf can jump directly to the next unfinished shelf.
